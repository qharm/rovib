.. _classes:

##############
Classes Design
##############

#. ``Molecule`` class.

   - Motivation: Describe the user's input.
   - State is the atomic symbols, XYZ coordinates, and isotopic masses.
   - Eventually replaced by SimDE's ``ChemicalSystem`` class.

#. ``Hamiltonian`` class.

   - Container for all the Hamiltonian terms.
   - Will eventually get replaced by SimDE's ``Hamiltonian`` class.

#. ``HamiltonianTerm`` class.

   - Base class for all Hamiltonian terms.
   - Will eventually get replaced by a SimDE class.

#. ``HarmonicHamiltonian`` class.

   - |omegavec| which is |Nvib| element vector

#. ``AnharmonicPotential`` class.

   - State is ``CubicPotential`` and ``QuarticPotential`` objects.

#. ``VibrationalCoriolisHamiltonian`` class.

   - State is ``CoriolisOperator`` and ``WatsonOperator`` objects.

#. ``RovibrationalHamiltonian`` class.

    - |zetavec| which is |Nvib| by 3 by |Nvib|
    - |etavec| list

#. ``VibrationalBasisFunction`` class.

   - Product of |Nvib| harmonic oscillator wavefunctions.
   - Class state is a vector of vibrational quantum numbers.

#. ``RotationalBasisFunction`` class.

   - Angular momentum eigenstate.
   - Class state is J and K.

#. ``RovibrationalBasisFunction`` class.

   - Contains a ``VibrationalBasisFunction`` and a ``RotationalBasisFunction``.

#. ``VibrationalAnsatz`` class.

   - State is conceptually a vector of ``VibrationalBasisFunction`` objects.
   - In practice, basis functions are generated on-the-fly.

#. ``RotationalAnsatz`` class.

   - State is conceptually a vector of ``RotationalBasisFunction`` objects.
   - In practice, basis functions are generated on-the-fly.

#. ``RovibrationalAnsatz`` class.

   - State is a  ``RotationalAnsatz`` and a ``VibrationalAnsatz``.

*********************
Vibrational Operators
*********************

#. ``NormalMode`` class.

   - State is the normal mode index and the frequency of the mode.

#. ``ConjugateMomentum`` class.

   - State is the normal mode index and the frequency of the mode.

All of the below classes have a method, ``vibrational_operators``, that returns
an object that can be iterated over. Each iteration returns a list of
vibrational operators (``NormalMode`` or ``ConjugateMomentum``) operators. The
classes also have a method ``coefficient``. The inputs to ``coefficient``
are assumed to be generated by the ``vibrational_operators`` method.

#. ``PotentialOperator``

   - State is the order (either 3 or 4), the number of vibrations, |Nvib|, the
     force constants :math:`\Nvib^{order}`, and the frequencies |omegavec|
     (needed to build the ``NormalMode`` objects).
   - ``coefficient`` returns the force constant scaled appropriately for the
     term.
   - ``vibrational_operators`` loops tuples of length "order" where each tuple
     contains ``NormalMode`` objects corresponding to modes taken from the
     numbers 0 to |Nvib| choose "order" with replacement.

#. ``CoriolisOperator`` class.

   - The :math:`\pivec` operator in the background.
   - State is the Coriolis coupling matrix, |zetavec|, the number of
     vibrations, |Nvib|, and the frequencies |omegavec| (needed to build the
     ``NormalMode`` and ``ConjugateMomentum`` objects).
   - ``coefficient`` returns the 3 element tensor :math:`\tens{\zeta_{ij}}`.
   - ``vibrational_operators`` loops over ``NormalMode`` and
     ``ConjugateMomentum`` pairs where the modes of each operator run from 0
     to |Nvib|.

#. ``WatsonOperator`` class.

   - This is the `\muvec` operator from Watson's Hamiltonian.
   - State is |Nvib|, the order of the operator, the :math:`\tens{a}`, the
     rotational constants, and the frequencies |omegavec| (needed to build the
     ``NormalMode`` objects).
   - ``coefficient`` returns 3 by 3 matrix :math:`\tens{\eta^{\midx_n}}`.
   - ``vibrational_operators`` returns tuples of ``NormalMode`` objects.

********************
Rotational Operators
********************

#. ``JOperator`` class.

   - State is the rotational quantum numbers ``J`` and the projection.
   - ``act`` acts on a value of ``K`` and returns the resulting values of ``K``
     and the corresponding coefficients.

#. ``RigidRotorHamiltonian`` class.

   - Rotational constants only. No ``J``.
   - ``rotational_operators(ket)`` returns the ``JOperator`` objects that
     act on the provided ``ket`` which is a ``RotationalAnsatz`` object.
