Classes Design

  1. Molecule class.

    • Motivation: Describe the user’s input.

    • State is the atomic symbols, XYZ coordinates, and isotopic masses.

    • Eventually replaced by SimDE’s ChemicalSystem class.

  2. Hamiltonian class.

    • Container for all the Hamiltonian terms.

    • Will eventually get replaced by SimDE’s Hamiltonian class.

  3. HamiltonianTerm class.

    • Base class for all Hamiltonian terms.

    • Will eventually get replaced by a SimDE class.

  4. HarmonicHamiltonian class.

    • \(\omegavec\) which is \(\Nvib\) element vector

  5. AnharmonicPotential class.

    • State is CubicPotential and QuarticPotential objects.

  6. RigidRotorHamiltonian class.

    • Rotational constants

  7. VibrationalCoriolisHamiltonian class.

    • \(\zetavec\) which is \(\Nvib\) by 3 by \(\Nvib\)

    • \(\etavec\) list

  8. RovibrationalHamiltonian class.

    • \(\zetavec\) which is \(\Nvib\) by 3 by \(\Nvib\)

    • \(\etavec\) list

  9. WatsonHamiltonian class.

    • \(\etavec\) list.

    • Technically only need diagonal elements of \(\etavec\).

  10. RovibrationalBasisFunction class.

    • Product of \(\Nvib\) harmonic oscillator wavefunctions and an angular momentum eigenstate.

    • Class state is a vector of vibrational quantum numbers, J, and K.

  11. RovibrationalAnsatz class.

    • State is conceptually a vector of RovibrationalBasisFunction objects.

    • In practice, basis functions are generated on-the-fly.

Vibrational Operators

  1. NormalMode class.

    • State is the normal mode index and the frequency of the mode.

  2. ConjugateMomentum class.

    • State is the normal mode index and the frequency of the mode.

All of the below classes have a method, vibrational_operators, that returns an object that can be iterated over. Each iteration returns a list of vibrational operators (NormalMode or ConjugateMomentum) operators. The classes also have a method coefficient. The inputs to coefficient are assumed to be generated by the vibrational_operators method.

  1. PotentialOperator

    • State is the order (either 3 or 4), the number of vibrations, \(\Nvib\), the force constants \(\Nvib^{order}\), and the frequencies \(\omegavec\) (needed to build the NormalMode objects).

    • coefficient returns the force constant scaled appropriately for the term.

    • vibrational_operators loops tuples of length “order” where each tuple contains NormalMode objects corresponding to modes taken from the numbers 0 to \(\Nvib\) choose “order” with replacement.

  2. CoriolisOperator class.

    • The \(\pivec\) operator in the background.

    • State is the Coriolis coupling matrix, \(\zetavec\), and the number of vibrations, \(\Nvib\).

    • coefficient returns the 3 element tensor \(\tens{\zeta_{ij}}\).

    • vibrational_operators loops over NormalMode and ConjugateMomentum pairs where the modes of each operator run from 0 to \(\Nvib\).

  3. WatsonOperator class.

    • This is the muvec operator from Watson’s Hamiltonian.

    • State is \(\Nvib\), the order of the operator, the \(\tens{a}\), and the rotational constants.

    • coefficient returns 3 by 3 matrix \(\tens{\eta^{\midx_n}}\).

    • vibrational_operators returns tuples of NormalMode objects.
