class rovib.molecule.Molecule(symbols, coords, masses)

The user’s description of a (non-linear) molecule.

This class is a stand-in for SimDE’s ChemicalSystem class. The coordinates and masses are stored as read-only arrays.

class rovib.rovibrational_ansatz.RovibrationalAnsatz(nvib, vmax, J)

The space in which the Hamiltonian is diagonalized.

The space is the direct product of harmonic oscillator states, with \(0 \le v_k \le v_{\max}\) for every mode, and the angular momentum states \(\ket{J,K}\) with \(K = -J, \ldots, J\) for a single \(J\). Only the truncation parameters are stored; basis functions are generated on demand.

Basis functions are ordered with the first mode’s quantum number varying slowest and \(K\) varying fastest.

Parameters:

  • nvib (int) – The number of vibrational modes.

  • vmax (int) – The maximum vibrational quantum number of each mode.

  • J (int) – The total angular momentum quantum number.

Raises:

ValueError – If nvib is less than 1 or if vmax or J is negative.

class rovib.hamiltonian_term.HamiltonianTerm

Base class for the terms of a Hamiltonian.

Terms carry the state needed to evaluate their matrix elements, but otherwise serve as a domain-specific language for specifying which terms are in the Hamiltonian. Matrix elements are evaluated by separate functions (see rovib.matrix_elements.hamiltonian_matrix).

Adding two terms, or a term and a Hamiltonian, gives a Hamiltonian.

class rovib.anharmonic_potential.AnharmonicPotential(frequencies, cubic, quartic)

The anharmonic potential \(\Vanharm\).

The force constants are the derivatives of the potential with respect to the mass-weighted normal coordinates, i.e.,

\[\Vanharm = \frac{1}{3!}\sum_{ijk=1}^{\Nvib} g_{ijk}\qop_i\qop_j\qop_k + \frac{1}{4!}\sum_{ijkl=1}^{\Nvib} h_{ijkl}\qop_i\qop_j\qop_k\qop_l\]

The harmonic frequencies are needed because the matrix elements of \(\qop_i\) depend on \(\omega_i\). All inputs are stored as read-only arrays. See Anharmonic Potential for the matrix elements.

Parameters:

  • frequencies (numpy.ndarray) – The harmonic frequencies \(\omegavec\) in hartree. The shape is (number of vibrational modes,).

  • cubic (numpy.ndarray) – The cubic force constants \(g_{ijk}\) in atomic units. The shape is (nvib, nvib, nvib).

  • quartic (numpy.ndarray) – The quartic force constants \(h_{ijkl}\) in atomic units. The shape is (nvib, nvib, nvib, nvib).

Raises:

ValueError – If frequencies is not a non-empty vector, if any frequency is not positive, or if cubic or quartic has the wrong shape or is not symmetric under permutation of its indices.

class rovib.vibrational_coriolis_hamiltonian.VibrationalCoriolisHamiltonian(frequencies, coriolis_couplings, inertia_derivatives, rotational_constants)

The vibrational Coriolis Hamiltonian \(\HvibCor\).

In atomic units,

\[\HvibCor = \frac{1}{2}\sum_{n=0}^{2}\pivec^T\muvec^{(n)}\pivec - \frac{1}{8}\sum_{n=0}^{4}\tr(\muvec^{(n)})\]

The harmonic frequencies are needed because the matrix elements of \(\qop_i\) and \(\pop_i\) depend on \(\omega_i\). All inputs are stored as read-only arrays. See Vibrational-Coriolis Hamiltonian for the matrix elements.

Parameters:

  • coriolis_couplings (numpy.ndarray) – The Coriolis coupling constants \(\zetavec\), indexed by (\(i\), \(\alpha\), \(j\)). The shape is (nvib, 3, nvib).

  • inertia_derivatives (numpy.ndarray) – The derivatives of the inertia tensor \(\avec\) in atomic units, indexed by (\(k\), \(\alpha\), \(\beta\)). The shape is (nvib, 3, 3).

  • rotational_constants (numpy.ndarray) – The rotational constants \(\gammavec\) in hartree. These must be in the same axes as coriolis_couplings and inertia_derivatives.

Raises:

ValueError – If frequencies is not a non-empty vector, if any frequency or rotational constant is not positive, if any input has the wrong shape, or if coriolis_couplings is not antisymmetric in \(i\) and \(j\).

class rovib.operators.potential_operator.PotentialOperator(force_constants, frequencies)

One order of the Taylor expansion of the potential.

For order \(m\) the operator is

\[\frac{1}{m!}\sum_{i_1,\ldots,i_m=1}^{\Nvib} F_{i_1\ldots i_m}\qop_{i_1}\cdots\qop_{i_m}\]

The \(\qop_i\) commute, so the sum is restricted to \(i_1 \le \ldots \le i_m\) and the coefficients are scaled to account for the terms that were combined.

Like the other operators made of sums of products of single-mode operators (see Classes Design), vibrational_operators() returns the products and coefficient() returns the coefficient of one of them.

Parameters:

  • force_constants (numpy.ndarray) – The force constants \(F_{i_1\ldots i_m}\) in atomic units. The shape is (nvib,) * order and the tensor is assumed to be symmetric.

  • frequencies (numpy.ndarray) – The harmonic frequencies \(\omegavec\) in hartree. The shape is (nvib,).

Raises:

ValueError – If force_constants is not of shape (nvib,) * order for some order >= 1.

property order

The order of the operator, \(m\).

Return type:

int

vibrational_operators()

The products of normal modes in the operator.

Returns:

Return type:

collections.abc.Iterable

coefficient(operators)

The coefficient of a product of normal modes.

Parameters:

operators (tuple) – A product returned by vibrational_operators().

class rovib.operators.watson_operator.WatsonOperator(order, inertia_derivatives, rotational_constants, frequencies)

One order of the Taylor expansion of the Watson mu tensor \(\muvec\).

For order \(n\) the operator is

\[\muop^{(n)}_{\alpha\beta} = \sum_{\midx_n} \eta^{\midx_n}_{\alpha\beta}\qop_{\midx_n}\]

so coefficient() returns a matrix, with one element per component. The matrices are combined with the coefficients of the other factors of the operator by the reducer (see vibrational_matrix()). Unlike PotentialOperator, the sum runs over all multi-indices because \(\eta^{\midx_n}_{\alpha\beta}\) is not symmetric under permutation of the multi-index. See Watson mu Tensor for its definition.

Like the other operators made of sums of products of single-mode operators (see Classes Design), vibrational_operators() returns the products and coefficient() returns the coefficient of one of them.

Parameters:

  • order (int) – The order of the operator, \(n\).

  • inertia_derivatives (numpy.ndarray) – The derivatives of the inertia tensor \(\avec\), indexed by (\(k\), \(\alpha\), \(\beta\)). The shape is (nvib, 3, 3).

  • rotational_constants (numpy.ndarray) – The rotational constants \(\gammavec\) in hartree. These must be in the same axes as inertia_derivatives.

  • frequencies (numpy.ndarray) – The harmonic frequencies \(\omegavec\) in hartree. The shape is (nvib,).

Raises:

ValueError – If order is negative, if inertia_derivatives is not of shape (nvib, 3, 3), or if rotational_constants is not of shape (3,).

The order of the operator, \(n\).

Matrix elements of the rigid rotor Hamiltonian.

\(\HRR\) is diagonal in \(\vvec\) and \(J\), and couples \(K\) only to \(K\) and \(K\pm 2\):

\[\braket{\vvec',J',K'\mid \HRR\mid\vvec,J,K} = \delta_{\vvec',\vvec}\delta_{J',J}\left( T^{(\text{RR},0)}_{J,K',K} + T^{(\text{RR},-2)}_{J,K',K} + T^{(\text{RR},2)}_{J,K',K}\right)\]

where:

\[\begin{split}T^{(\text{RR},0)}_{J,K',K} \equiv& \delta_{K',K}\left[ \frac{\gamma_x+\gamma_y}{2} \left(J(J+1) - K^2\right) + \gamma_z K^2\right]\\ T^{(\text{RR},-2)}_{J,K',K} \equiv& \delta_{K',K-2} \frac{\gamma_x-\gamma_y}{4} C^-_{J,K}C^-_{J,K-1}\\ T^{(\text{RR},2)}_{J,K',K} \equiv& \delta_{K',K+2} \frac{\gamma_x-\gamma_y}{4} C^+_{J,K}C^+_{J,K+1}\end{split}\]

and \(C^\pm_{J,K} = \sqrt{J(J+1) - K(K\pm1)}\). See Rigid Rotor Hamiltonian for the derivation.

Matrix elements of products of vibrational operators.

Implements “Vibrational Basis: Algorithm 1” from Evaluating Matrix Elements. Operators on different modes commute, so a matrix element of a product of single-mode operators factors into one matrix element per mode,

\[\braket{\vvec'\mid\op{O}_1\cdots\op{O}_m\mid\vvec} = \prod_{n=1}^{\Nvib}\braket{v'_n\mid\op{O}^{(n)}\mid v_n}\]

where \(\op{O}^{(n)}\) is the product, in the original order, of the operators acting on mode \(n\) (the identity if there are none).

rovib.matrix_elements.vibrational_matrix_elements.vibrational_matrix(bra_space, ket_space, operators, reducer)

Builds the matrix of a product of vibrational operators.

operators is a list of objects that each represent a sum of products of single-mode operators, e.g., PotentialOperator. The operator whose matrix is built is the product of the elements of operators, in order, with each term’s coefficient given by reducer. The operator is assumed to be purely vibrational, so it only couples basis functions with the same \(J\) and \(K\).

Parameters:

  • bra_space (RovibrationalAnsatz) – The space the bra basis functions come from.

  • ket_space (RovibrationalAnsatz) – The space the ket basis functions come from.

  • operators (list) – The factors of the operator.

  • reducer (collections.abc.Callable) – Combines a list holding the coefficient of one product from each element of operators into the coefficient of their product. Products whose coefficient is zero are skipped.

Returns:

The matrix of the operator in atomic units. The shape is (len(bra_space), len(ket_space)).

Return type:

numpy.ndarray

Builds the matrix of a Hamiltonian in a rovibrational ansatz.

build_matrix() dispatches on the type of the term. Terms that are products of vibrational operators (e.g., AnharmonicPotential) are evaluated with vibrational_matrix(). For the remaining terms, the elements returned by non_zero_indices() are evaluated one at a time with the term’s matrix element function.

rovib.inertia.inertia_derivatives(molecule, normal_modes)

Computes the derivatives \(\avec\) of the inertia tensor of a molecule.

\[a_{k,\alpha\beta} = 2 \sum_{i=1}^{\Natom} \sum_{\gamma,\delta=1}^{3} \left(\delta_{\alpha\beta}\delta_{\gamma\delta} - \delta_{\alpha\delta}\delta_{\beta\gamma}\right) \sqrt{M_i}\, r_{i,\gamma}^0 L_{i,k,\delta}\]

\(\avec_k\) is only symmetric if \(\Lvec\) satisfies the Eckart conditions at the geometry of molecule. No attempt is made to symmetrize the result, so normal modes with limited precision give an \(\avec_k\) that is only symmetric to that precision.

Return type:

numpy.ndarray

rovib.inertia.rotational_constants(molecule, ordering=(1, 3, 2))

Computes the rotational constants \(\gammavec\) of a molecule.

The rotational constants are \(\gamma_\alpha = \frac{\hbar^2}{2I^0_{\alpha\alpha}}\), where the \(I^0_{\alpha\alpha}\) are the principal moments of inertia, i.e., the eigenvalues of the inertia tensor \(\Izvec\) at the minimum energy geometry.

Diagonalizing \(\Izvec\) does not say which principal axis is x, y, or z; ordering does. ordering[i] is the rank (1 being the smallest) of the rotational constant assigned to the i-th axis. The default, (1, 3, 2), is the convention of doi:10.1063/5.0333947: x has the smallest rotational constant, y the largest, and z the middle one. The axes used for other quantities (e.g., the normal modes) must follow the same convention.

Parameters:

  • molecule (Molecule) – The molecule, at its minimum energy geometry, with its center of mass at the origin.

  • ordering (tuple of int) – A permutation of (1, 2, 3) giving the rank of the rotational constant of each axis. A string such as "132" is also accepted.

Returns:

The rotational constants \((\gamma_x, \gamma_y, \gamma_z)\) in hartree.

Return type:

numpy.ndarray

Raises:

ValueError – If ordering is not a permutation of (1, 2, 3), or if a principal moment of inertia is zero (i.e., the molecule is linear).

Hard-coded parameters for water.

Unless noted otherwise, the parameters are from Appendix B of E. Lötstedt and T. Szidarovszky, J. Chem. Phys. 165, 024118 (2026), doi:10.1063/5.0333947. The functions in this module return the parameters in atomic units.

The molecule-fixed axes are those of the paper: x (the paper’s a axis) is perpendicular to the molecular plane, y (b) is in the plane, and z (c) is the C2 axis. The atoms are ordered O, H1, H2, and the vibrational modes are ordered symmetric stretch, bend, antisymmetric stretch.

This file was generated by Claude. RMR has verified that the parameters in this file are consistent with 10.1063/5.0333947.

rovib.water_params.water_molecule()

Returns the equilibrium geometry of water.

The paper only gives the O-H distance and the H-O-H angle. The Cartesian coordinates are derived from them, with the center of mass at the origin and the axes described in the module documentation.

This fixes the coordinates up to the sign of the inversion \(\rzvec \rightarrow -\rzvec\), which the Eckart conditions cannot determine. The orientation used here has O on the -z side of the center of mass and H1 at y < 0, which is the orientation that reproduces the paper’s results. Note that, with the paper’s normal-mode matrix, a positive displacement along the symmetric stretch then compresses the O-H bonds.

Returns:

Water at its equilibrium geometry.

Return type:

Molecule
